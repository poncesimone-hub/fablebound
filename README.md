## 📖 Sobre o Jogo

**Laura: A Maga do Conto de Fadas** é um jogo de ação estilo **Run and Gun** onde você controla Laura, uma jovem maga que aprende 3 tipos de magia diferentes para derrotar bosses em um mundo de fantasia.

### ✨ Características

✅ **Personagem Laura** com mecânicas avançadas:
- Pulo duplo
- Dash (velocidade aumentada)
- 3 tipos de magia (Raio ⚡, Gelo ❄️, Fogo 🔥)

✅ **Sistema de Magia:**
- Magia de Raio (rápida e precisa)
- Magia de Gelo (congelante)
- Magia de Fogo (poderosa)

✅ **Super Ataques (Ultimates):**
- Grande Raio
- Geleira
- Raio de Fogo

✅ **Sistema de Relíquias:**
- Relíquia de Vida (aumenta HP)
- Relíquia de Velocidade (movimento mais rápido)
- Relíquia de Rapidez (especial carrega mais rápido)

✅ **9 Bosses Diferentes:**
1. Dragão
2. Cavaleiro
3. Mago
4. Bruxa
5. Gigante
6. Princesa
7. Rei
8. Boss intermediário
9. O Livro (Boss Final)

✅ **3 Fases:**
- Floresta do Terror
- Biblioteca
- Coliseu

✅ **Loja com Vendedor Quill:**
- Compre tiros de magia
- Compre relíquias
- Ganhe moedas completando fases

## 💻 Versões Disponíveis

### **Versão Web (Recomendada)**
- 🌐 Joga direto no navegador
- 📱 Funciona em celular e PC
- ⚡ Sem instalação
- 🔗 Link: https://poncesimone-hub.github.io/fablebound/

### **Versão Python (Pygame)**
Para rodar localmente:

1. Clone o repositório:
```bash
git clone https://github.com/poncesimone-hub/fablebound.git
cd fablebound
git checkout game-laura-maga
```

2. Instale as dependências:
```bash
pip install -r requirements.txt
```

3. Execute o jogo:
```bash
python src/main.py
```

### **Versão Replit**
Para rodar online (sem instalação):

1. Acesse: https://replit.com/new/python
2. Cole no terminal:
```bash
git clone https://github.com/poncesimone-hub/fablebound.git && cd fablebound && git checkout game-laura-maga && pip install -r requirements.txt && python src/main.py
```

## 🎯 Objetivo do Jogo

1. **Derrotar os Bosses** - Use suas magias para vencer cada inimigo
2. **Ganhar Moedas** - Ganhe moedas completando fases
3. **Comprar Itens** - Na loja, compre tiros e relíquias
4. **Ficar Mais Forte** - Aumente seu poder com relíquias
5. **Vencer o Boss Final** - Derrote O Livro e complete a aventura!
