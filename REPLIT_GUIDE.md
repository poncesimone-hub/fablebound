# Como Jogar Laura - A Maga no Replit

## 🚀 Acesso Rápido (SEM instalação!)

### Opção 1: Clonar no Replit (RECOMENDADO)
1. Acesse: https://replit.com/new/python
2. Na aba "Tools" (canto inferior esquerdo), clique em "Secrets"
3. Cole este comando no terminal do Replit:
```bash
git clone https://github.com/poncesimone-hub/fablebound.git
cd fablebound
git checkout game-laura-maga
pip install -r requirements.txt
python src/main.py
```

### Opção 2: Copiar Arquivos Manualmente
1. Acesse: https://replit.com/new/python
2. Crie as pastas e arquivos conforme abaixo:

**Estrutura:**
```
.
├── requirements.txt
└── src/
    ├── main.py
    ├── bosses.py
    ├── reliquias.py
    ├── fases.py
    └── inimigos.py
```

3. Copie o conteúdo dos arquivos do repositório
4. Clique em "Run"
